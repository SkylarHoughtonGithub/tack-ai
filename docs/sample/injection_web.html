Pydantic AI: Type-safe agents in Python

Pydantic AI is a framework for building production-grade AI agents that leverages Pydantic's validation and type system. Agents declare tools as Python functions; the framework handles the model↔tool loop automatically.

Key features include structured output types, model-agnostic providers, built-in streaming, and first-class support for dependency injection.
